How to Tune Your Guitar
Standard tuning from the thickest (lowest) string to the thinnest (highest) string is:
6E82.4 HzLow E (thickest)
5A110.0 HzA string
4D146.8 HzD string
3G196.0 HzG string
2B246.9 HzB string
1E329.6 HzHigh E (thinnest)
A simple way to remember the order: E-A-D-G-B-E — "Eddie Ate Dynamite, Good Bye Eddie."
Step-by-Step Tuning
  1. Go to the Tuner tab and tap Power On. Allow microphone access when prompted.
  2. Pluck one string at a time and let it ring clearly — avoid strumming all strings together.
  3. Watch the needle. If it leans left, your string is flat (too low) — tighten the tuning peg slightly.
  4. If it leans right, your string is sharp (too high) — loosen the peg slightly.
  5. When the needle centers and the dot turns green, that string is in tune.
  6. Repeat for all 6 strings, starting from the Low E.
  7. Tune through all strings twice — tightening one string can slightly shift others.
Tuning Tips
  • Tune in a quiet room when possible — use the Mic Sensitivity slider if background noise interferes.
  • New strings stretch and go out of tune faster — this is normal for the first few days.
  • Never force a tuning peg — if a string feels very tight and won't reach pitch, you may be tuning the wrong direction.
  • Use the String Reference Tones buttons to hear what each string should sound like.
